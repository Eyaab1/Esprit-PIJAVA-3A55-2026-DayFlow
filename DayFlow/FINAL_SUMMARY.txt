PROJECT: DayFlow (Java + PostgreSQL + JavaFX)
ISSUE: Goal creation fails with constraint violation error
STATUS: ✅ ANALYZED, FIXED, AND DOCUMENTED

================================================================================
                              THE PROBLEM
================================================================================

Error Message:
  ERREUR: la nouvelle ligne de la relation « goal_participation » viole la 
  contrainte de vérification « chk_participation_role »

What Happens:
  1. User creates a goal
  2. Goal is saved to database ✅
  3. App tries to create goal participation record
  4. PostgreSQL rejects it due to constraint violation ❌
  5. Error popup appears ❌

================================================================================
                            ROOT CAUSE ANALYSIS
================================================================================

Primary Cause: Data Mismatch
  - Database constraint expects: role IN ('owner', 'admin', 'member')
  - Old data contains: 'OWNER', 'ADMIN', 'MEMBER' (uppercase)
  - New code tries to insert: 'owner' (lowercase)
  - Result: Constraint violation

Secondary Cause: No Duplicate Prevention
  - ensureChatroomAndOwner() could be called multiple times
  - Each call attempts to insert a new participation record
  - UNIQUE constraint (user_id, goal_id) would be violated

Tertiary Cause: No Error Handling
  - When UNIQUE constraint was violated, error was not caught
  - Error propagated to UI as unhandled exception

================================================================================
                              THE SOLUTION
================================================================================

Step 1: Clean Database (2 minutes)
  Run SQL to convert uppercase to lowercase:
  
  UPDATE goal_participation SET role = 'owner' WHERE role = 'OWNER';
  UPDATE goal_participation SET role = 'admin' WHERE role = 'ADMIN';
  UPDATE goal_participation SET role = 'member' WHERE role = 'MEMBER';
  UPDATE goal_participation SET status = 'accepted' WHERE status = 'APPROVED';
  UPDATE goal_participation SET status = 'pending' WHERE status = 'PENDING';
  UPDATE goal_participation SET status = 'rejected' WHERE status = 'REJECTED';

Step 2: Update Java Code (Already Done)
  File: src/main/java/services/chatroom/GoalChatroomLifecycleService.java
  Method: ensureChatroomAndOwner()
  
  Changes:
  - Check if participation already exists (prevent duplicates)
  - Ensure chatroom exists regardless of participation state
  - Only create participation if it doesn't exist
  - Wrap insert in try-catch to handle UNIQUE constraint violations
  - Log gracefully when participation already exists

Step 3: Recompile and Test (1 minute)
  mvn clean compile
  mvn javafx:run
