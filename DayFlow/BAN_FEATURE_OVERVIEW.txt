┌──────────────────────────────────────────────────────────────────────────────┐
│                                 KEY FEATURES                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  ⏱️  TEMPORARY BAN
      • Duration: 1-365 days (default: 7)
      • User status: temp_banned
      • Expiration: banned_until timestamp

  🚫 PERMANENT BAN
      • Duration: Indefinite
      • User status: banned
      • No expiration

  🔔 IN-APP NOTIFICATIONS
      • Type: BAN
      • Content: Duration + Reason
      • No emails sent

  🛡️  BAN STATUS DISPLAY
      • Shows current ban status
      • Disables buttons if already banned
      • Color-coded indicators
